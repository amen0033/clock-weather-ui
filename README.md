# Clock & Weather UI

A clean, responsive **clock + weather** web app built with **HTML**, **CSS** and **JavaScript**.

## Features

- 🕐 **Live clock** — updates every second, with full date
- 🌤️ **Real weather** — current temperature, condition, humidity and wind via the free [Open-Meteo](https://open-meteo.com/) API (no API key needed)
- 🌍 **City selector** — Tunis, Sfax, Algiers, Paris, London, New York
- 🌙 **Dark / light mode** — toggle button, preference saved in `localStorage`
- 📱 **Responsive** — looks good on phone and desktop

## Live demo

🌐 **https://amen0033.github.io/clock-weather-ui/** (hosted free on GitHub Pages)

## Run locally

Just open `index.html` in a browser — no build step needed (weather needs an internet connection).

```
# or serve it locally
python3 -m http.server 8000
```
